Payroll Management System - Java

This project contains six separate Java source files:
1. Taxable.java
2. BonusCalculable.java
3. Employee.java
4. FullTimeEmployee.java
5. ContractorEmployee.java
6. PayrollSystem.java

How to run:
- Put all six .java files in the same folder.
- Open the folder in a Java IDE or terminal.
- Compile: javac *.java
- Run: java PayrollSystem

No package declaration is used, so all files should remain in the same folder.
Requires Java 8 or newer (LocalDate and Comparator are used).
